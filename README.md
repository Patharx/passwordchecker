# 🧙 Gandalf's Password Checker

A cybersecurity tool that analyzes password strength and delivers verdicts 
in the voice of Gandalf the Grey. Built with Python as part of a 
cybersecurity learning journey.

---

## 🔐 What It Checks

| Check | Max Score | Description |
|---|---|---|
| Length | 3 points | Longer passwords are exponentially harder to crack |
| Character Diversity | 4 points | Uppercase, lowercase, numbers, and symbols |
| Common Passwords | 1 point | Checks against known weak passwords |
| Patterns | 1 point | Detects repeated or sequential characters |

---

## 💪 Strength Ratings

- 🔴 **Very Weak** — Gandalf is deeply concerned
- 🔴 **Weak** — A Nazgul could crack this
- 🟡 **Medium** — Potential, but work remains
- 🟢 **Strong** — Worthy of Rivendell
- 🟢 **Very Strong** — Even Sauron couldn't crack this
